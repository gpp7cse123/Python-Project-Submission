PYTHON MICRO PROJECT: STUDENT MANAGEMENT SYSTEM

Files:
1. Python_Microproject_Report.docx - editable report for college submission
2. Python_Microproject_Presentation.pptx - presentation slides
3. student_management_system.py - working Python source code

How to run:
1. Install Python 3 if it is not already installed.
2. Put student_management_system.py in a folder.
3. Open IDLE or a terminal in that folder.
4. Run: python student_management_system.py
5. Choose menu options 1-6.
6. The program creates students.json automatically when records are saved.

Before submitting:
- Fill in all four group members' names and roll numbers.
- Fill in college, teacher/guide, and academic session.
- Run the program and add actual screenshots if required by your teacher.
- Confirm the required report format with your teacher.
