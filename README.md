
# Student Project Submission Portal

A Flask-based web application that allows students to submit their Python projects online for academic review.

## Features

- Student name and roll number submission
- Project title entry
- Project folder upload
- Organised storage of submitted projects in GitHub
- Online deployment using Render
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- GitHub API
- Render

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gpp7cse123/Python-Project-Submission.git
   ```

2. Open the project folder:

   ```bash
   cd Python-Project-Submission
   ```

3. Create and activate a virtual environment (optional but recommended).

4. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Configure the required environment variables:
   - `GH_OWNER`
   - `GH_REPO`
   - `GH_TOKEN`

   Keep your GitHub token secret. Never publish it in your code or README.

6. Start the application:

   ```bash
   python app.py
   ```

## Project Storage

## Important Notes

- Submit only your own academic projects.
- Do not upload passwords, API keys, or confidential information.
- Uploaded files may be publicly accessible if the GitHub repository is public.
